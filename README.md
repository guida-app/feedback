# Guida feedback

Public feedback for Guida's examples, documentation and guided alpha evaluations.
You do not need access to the private product repositories to participate.

- **Something failed or was confusing?** Open an issue with the task, product/version,
  steps, expected result and actual result. A small synthetic reproduction helps.
- **Have a useful example in mind?** Describe the data you need and the task it would solve.
- **Interested in guided Enterprise evaluation?** Use the evaluation request template
  to describe your goal and available setup. An issue starts a conversation; it does
  not automatically provision access or establish evaluation terms.

Issues here are public. Keep access tokens, private hostnames, customer/employer
data and confidential screenshots out of them. Existing evaluators should use
their agreed private support channel for installation-specific material.

Guida is independently developed. Response times depend on maintainer availability.
Enterprise is proprietary software; this repository contains no product source.
